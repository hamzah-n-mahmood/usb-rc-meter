Does each current source hold its current?

Experiment 1 put a growing resistor on each transistor current source and logged the current. A good source stays flat until the transistor runs out of headroom; then the current falls away.

Which stage should read which resistor?

Each stage turns one ADC count into a fixed number of ohms. With fewer than 100 counts, one count is worth more than 1 % of the reading. That's where auto-ranging should hand over to the next stage down.

Usable range of each stage

Solid: one count is 1 % of the reading or better, up to full scale (1023 counts). Pale: 10 to 100 counts, readable but coarse. Dashed lines: the range the thesis claimed.

Stage resolution

Ohms per count = 3.711 mV per count ÷ the stage current.

Why tiny capacitors read high

Experiment 4 simulated the 555 timing circuit in Proteus. Large capacitors read almost perfectly. Tiny ones read far too high: a handful of extra timer counts barely matters in a long pulse, but swamps a short one.

Size of the simulated error

Both axes are logarithmic. The dashed line is 1 %. The largest capacitor tried returned "Out of Range" and isn't plotted.

How close did the meter get?

Experiment 6 measured each part on the RC meter and on commercial meters. The fair question isn't "does it match the label?" but "does it agree with the reference meter within that meter's own uncertainty?"

Resistance error against the CD800a, 100 Ω to 1 MΩ

Grey bars: the CD800a's own ± uncertainty at each value. A dot inside its bar is as good as the reference can tell. Parts below 100 Ω are off this scale; see the next chart.

Below 100 Ω: a fixed offset

RC meter reading minus the CD800a reading. Roughly the same few ohms whatever the part, so it's an offset (lead and switch resistance, plus a count or two), not a gain error.

Capacitance error
